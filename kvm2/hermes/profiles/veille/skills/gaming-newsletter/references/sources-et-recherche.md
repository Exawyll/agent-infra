# Sources et Requêtes de Recherche — Newsletter Gaming

## Section 1 : Tendances Industrielles

### Requêtes
- `gaming industry news <dernières 2 semaines> major announcements acquisitions studio closures`
- `last 15 days video game news` (actualité générale)

### Sources clés
| Source | URL | Utilité |
|--------|-----|---------|
| Wikipedia — 2026 in video games | `en.wikipedia.org/wiki/<Année>_in_video_games` | Timeline des événements majeurs, licenciements, fermetures, annonces hardware — excellente vue d'ensemble |
| Northeastern Global News | `news.northeastern.edu` | Analyses contextuelles des crises industrielles |
| Polygon | `polygon.com` | Suivi des restructurations Xbox, Sony, etc. |
| IGN | `ign.com` | Annonces et réactions aux événements majeurs |
| GameSpot | `gamespot.com` | Calendrier des sorties + actualité |
| Xbox Wire | `news.xbox.com` | Annonces officielles Microsoft/Xbox — extraire directement les posts (ex: `/2026/07/06/resetting-xbox/`) |
| PlayStation Blog | `blog.playstation.com` | Annonces officielles Sony |
| Instagram/Facebook (IGN, Metacritic) | Via search web | Annonces officielles relayées |

### Cross-vérification des tendances

| Événement | Source primaire | Sources de recoupement |
|-----------|-----------------|----------------------|
| Restructuration Xbox/layoffs | Xbox Wire (post officiel) | CNBC, NYT, Polygon, GameSpot, GamesIndustry.biz — pour les chiffres exacts de licenciements |
| Annonce Sony physique | PlayStation Blog | TechCrunch, The Verge, Reddit (discussion) |
| Données Nintendo | Nintendo official | Eurogamer, Nintendo Life, Wikipedia |
| Chiffres métier | Wikipedia « <Année> in video games » | Sources journalistiques croisées dans la page |

### Catégories d'événements à surveiller
- Rachats / fusions / acquisitions
- Fermetures de studios
- Restructurations (CEO changes, layoffs)
- Annonces hardware (nouvelles consoles, Steam Machine, etc.)
- Décisions réglementaires (ex: "Stop Killing Games", Commission Européenne)
- Événements industry (Summer Game Fest, Gamescom, TGS, BlizzCon, The Game Awards)
- Fin de support de jeux live (ex: Destiny 2, Anthem)

## Section 2 : Sorties et Notes Metacritic

### Requêtes
- `video game releases last 15 days Metacritic scores`
- `best games this month Metacritic`
- `"<Titre du jeu>" Metacritic` (pour vérifier une note individuelle)

### Sources clés
| Source | URL | Utilité |
|--------|-----|---------|
| Metacritic — Notable Releases (recommended) | `metacritic.com/news/major-new-and-upcoming-video-games-ps5-xbox-switch-pc/` | **MEILLEURE SOURCE pour les sorties récentes.** Page mise à jour chaque semaine, liste les sorties à venir ET les sorties récentes, avec Metascore, genre, plateformes et date de sortie. Ajoute les jeux « Coming Soon » avec scores provisoires. |
| Metacritic — Best Games This Year | `metacritic.com/browse/game/all/all/current-year/` | Liste complète des jeux de l'année avec Metascore et date de sortie |
| Metacritic — Midyear Best of | `metacritic.com/pictures/best-video-games-of-<Année>-at-midyear/` | Top 20 du premier semestre (publié début juillet) |
| Metacritic — Page individuelle | `metacritic.com/game/<titre-du-jeu>/` | Score détaillé par plateforme, extraits de critiques |
| GameSpot — Biggest New Releases | `gamespot.com/gallery/the-biggest-new-game-releases-of-<Mois>-<Année>/` | Calendrier complet des sorties du mois |
| Wikipedia — <Année> in video games | `en.wikipedia.org/wiki/<Année>_in_video_games` | Tableau des jeux les mieux notés (Metacritic ≥ 90) |

### Pièges Metacritic
- **Scores par plateforme** : Un jeu peut avoir 80 sur PS5 et 74 sur PC. Toujours utiliser le score le plus favorable pour le filtre ≥ 80.
- **DLCs et rééditions** : Les DLCs (ex: DAVE THE DIVER: In the Jungle) et ports (ex: FFVII Rebirth Switch 2, DMC5 Devil Hunter Ed.) apparaissent dans les listes Metacritic avec leur propre score. Les inclure si ≥ 80.
- **Jeux en Early Access** : Peuvent avoir des scores provisoires. Vérifier qu'ils ont au moins 7 critiques (seuil Metacritic).
- **Jeux avec < 7 reviews** : Exclus des classements officiels Metacritic. Les ignorer.
- **Score « tbd »** : Les jeux sortis aujourd'hui ou hier affichent `tbd` (pas encore assez de critiques consolidées). Ne pas les inclure dans les tableaux. Les noter pour le sign-off si le jeu est suffisamment marquant (Palworld 1.0, Halo: Campaign Evolved, etc.).
- **Sorties Early Access → 1.0** : Un jeu quittant l'EA peut arriver sans score MC consolidé le jour J. Attendre le prochain cycle pour l'inclure dans le baromètre si le score ≥ 80.
- **Dernier jour de la période** : Les sorties du dernier jour du cycle (ex: le jour même) ont souvent des scores « tbd » et manqueront de recul critique. C'est normal — elles seront capturées dans le prochain run.

## Section 3 : Xbox Game Pass

### Requêtes
- `Xbox Game Pass last 15 days`
- `"<Titre du jeu>" Game Pass Metacritic`

### Sources clés

| Xbox Wire — Wave 2 | `news.xbox.com/en-us/<Année>/<mois>/<jour>/xbox-game-pass-<mois>-<année>-wave-2/` | Annonce officielle Wave 2 (mi-mois) |
